## Why UX?
A community information system project I worked on failed because I designed the interface based on how I think as a programmer, not based on how users actually work. The system worked technically, but the users could not use it. That failure taught me that being a good engineer is not just about writing code—it's about understanding the people who use that code.

This portfolio documents my journey learning UX design through the Google UX Design Professional Certificate. Each project represents a step toward my goal of becoming a human-centered technology designer.
